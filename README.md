# Customer Lifetime Value Prediction

Predict which existing retail customers will make no purchase, regular purchases or high-value purchases in the next 91 days. Future purchase revenue is a **CLTV proxy**, not proven lifetime revenue or profit.

Uses genuine [UCI Online Retail](https://archive.ics.uci.edu/dataset/352/online-retail) transactions (Chen, 2015; CC BY 4.0). No original project data or code was present. [Data provenance](data/README.md) documents cleaning, windows and differences from the historical project.

The downloaded workbook has **541,909 lines and 4,372 identified customers**. Cleaning retains **392,692 lines / 4,338 customers**. The prediction cohort contains **3,317 customers**, split into **2,653 training / 664 test** customers.

Explore the [executed EDA](notebooks/01_exploration.ipynb), [customer segmentation](notebooks/02_customer_segmentation.ipynb) and [execution report](results/report.md) directly on GitHub. Saved predictions, metrics and charts are included.

To reproduce the full pipeline with Python 3.12:

```bash
python run_project.py
```

This creates `.venv`, installs libraries, downloads UCI data, prepares features, trains models, executes both notebooks and verifies saved-model predictions. First run requires internet access.

History: **1 December 2010–31 August 2011**. Future target: **1 September–30 November 2011**. Nineteen inputs capture RFM, first-observed tenure, order values, cadence, recent activity and product breadth. PCA compresses log-scaled RFM; four K-Means cohorts describe behavior. Segment indicators, PCA coordinates and centroid distances join historical features in XGBoost, which models nonlinear interactions.

Customers split 80/20 by identity. Imputation, scaling, PCA and K-Means fit inside each CV training fold. Tiers are zero spending, positive spending up to the training positive-spender median, and spending above that median. Each fold learns its own boundary; final evaluation uses the full-training boundary. A 12-candidate, five-fold `RandomizedSearchCV` selects by macro F1.

| Evaluation | Accuracy | Macro F1 |
|---|---:|---:|
| Selected XGBoost, five-fold CV mean ± SD | 58.39% ± 2.23% | 0.5422 ± 0.0164 |
| XGBoost, held-out customers | 58.13% | 0.5474 |
| Majority baseline, held-out customers | 42.92% | 0.2002 |

The historical **>85% accuracy was not reproduced**. Segment features, transaction/tenure/cadence features and five-fold tuning were reproduced. RFM and segment assignments cover 3,317 customers; PCA/K-Means fit on 2,653 training customers. This qualifies the 3,000+ claim. Original dataset/target/splits are unavailable.

Per-class precision/recall and the full claim audit are in the [execution report](results/report.md). [Metrics](results/metrics.json), [CV candidates](results/cv_results.csv), [verification](results/verification.json), [execution log](results/execution.log) and [artifact manifest](results/artifact_manifest.csv) provide computed evidence.

The existing compact fitted models are included. To run inference without retraining, install the pinned dependencies in a local environment:

```bash
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
.venv/Scripts/python.exe -m scripts.predict --input data/processed/prediction_features.csv --output results/new_predictions.csv
```

On macOS/Linux, use `.venv/bin/python` for this optional command. Input schema: `models/model_metadata.json`.

Limitations: one prediction date, left-censored tenure, gross revenue excluding refunds, and no margins or causal marketing evaluation. Later-period robustness and incremental segmentation benefit are untested. Raw datasets and the large processed transaction table are excluded from Git and downloaded or generated by the full pipeline; compact fitted models, customer tables, executed notebooks and benchmark evidence are retained. The artifact manifest records the original local run, including files excluded from Git.
